\# Contributing to rasterPoints



Thank you for your interest in contributing to `rasterPoints`! Even though this project is currently maintained by a single developer, community contributions, bug reports, and feature requests are very welcome.



\## How to Contribute



1\. \*\*Reporting Bugs:\*\* Please open an issue on GitHub describing the bug, providing a minimal reproducible example (reprex), and stating your session information (`sessionInfo()`).

2\. \*\*Feature Requests:\*\* Open an issue to discuss proposed enhancements or new algorithms before submitting a pull request.

3\. \*\*Pull Requests:\*\* 

&#x20;  - Fork the repository and create your branch from `main`.

&#x20;  - Ensure all C++ code compiles without warnings.

&#x20;  - Run `devtools::test()` to confirm all unit tests pass.

&#x20;  - Submit the PR with a clear summary of changes.
